01 សេចក្ដីផ្ដើម៖ CSS Layout គឺជាអ្វី?

CSS Layout គឺជារបៀបដែលយើងកំណត់ទីតាំង ទំហំ និងលំដាប់របស់ធាតុ HTML នៅលើអេក្រង់។

ហេតុអ្វីសំខាន់?

  • ធ្វើឱ្យវេបសាយប្រើបានលើទូរស័ព្ទ
  • កាត់បន្ថយការសរសេរ code ដែលច្រេះ

07 CSS Grid — រៀបធាតុតាម ២ ទិស

.grid{
  display:grid;
  grid-template-columns:repeat(3,1fr);
  grid-template-rows:auto 1fr auto;
  gap:16px;
}
.a{grid-column:1 / 4;}   // ពេញ 3 列
.b{grid-row:2 / 4;}      // ឆ្លង 2 行

09 Flexbox ឬ Grid? តើត្រូវប្រើមួយណា

🎯 ប្រើ Flexbox នៅពេល…

  • តម្រៀបធាតុតាម ១ បន្ទាត់ ឬ ១ ជួរ
  • ទំហំធាតុមិនស្គាល់ទេ (content-driven)
  • navbar, button group, chip list
  • តម្រៀបកណ្ដាល vertical + horizontal

🧩 ប្រើ Grid នៅពេល…

  • ត្រូវការ ២ ទិស (row និង column)
  • រចនាសម្ព័ន្ធទំព័រទាំងមូល
  • gallery, dashboard, table-like layout
  • ចង់កំណត់ជួរទុកជាមុន (layout-driven)

💬 ពួកគេមិនប្រកួតប្រជែងគ្នាទេ — ប្រើ Grid សម្រាប់ page skeleton ហើយ Flexbox សម្រាប់ធាតុខាងក្នុង។

10 Responsive Layout

/* Mobile-first: សរសេរ style តូចមុន */
.card-grid{display:grid;grid-template-columns:1fr;gap:16px}

@media (min-width:640px){ .card-grid{grid-template-columns:repeat(2,1fr)} }
@media (min-width:1024px){ .card-grid{grid-template-columns:repeat(3,1fr)} }

Technique សំខាន់

  • %, fr, auto ជំនួស px ថេរ
  • clamp() សម្រាប់ font-size រលូន
  • aspect-ratio សម្រាប់រូបភាព
  • picture + srcset សម្រាប់រូប

Unit ដែលគួរដឹង

  • rem = ឯកតាមូលដ្ឋាន (accessible)
  • vw/vh = % viewport
  • ch = ទទឹងតួអក្សរ 0
  • dvh = viewport ពិតលើ mobile

11 លំហាត់អនុវត្ត (Class Activity)

① កម្រិតចាប់ផ្ដើម (15 នាទី)

បង្កើត navbar: logo ឆ្វេង links កណ្ដាល button ស្ដាំ ដោយ Flexbox តែមួយ។

② កម្រិតមធ្យម (25 នាទី)

Card grid ៦ សន្លឹក: 1 列 mobile, 2 列 tablet, 3 列 desktop ដោយ auto-fit + minmax។

③ កម្រិតខ្ពស់ (30 នាទី)

Holy Grail layout ដោយ grid-areas: header / sidebar-main-aside / footer ហើយ sticky header។

④ Challenge បញ្ចប់មេរៀន

បង្កើត landing page ខ្លួនឯង 1 ទំព័រ ដែល responsive ពេញលេញ ហើយ submit លើ GitHub。

12 កំហុសទូទៅ & ដំបូន្មាន

❌ កុំធ្វើ

  • ប្រើ float / absolute សម្រាប់ layout ទាំងមូល
  • កំណត់ height ថេរ ដែល content អាចលើស
  • ប្រើ px សម្រាប់ font-size ទាំងអស់
  • ភ្លេច box-sizing:border-box
  • Nested grid ច្រើនពេក ដោយគ្មានហេតុផល

✅ គួរធ្វើ

  • Mobile-first ហើយ test លើ device ពិត
  • DevTools → badge flex/grid ដើម្បីមើល structure
  • ប្រើ gap ជំនួស margin hack
  • រក្សា semantic HTML មុន style
  • Check contrast និង keyboard navigation
